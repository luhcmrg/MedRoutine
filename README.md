# MedRoutine

## Sobre o projeto

O MedRoutine é um projeto acadêmico desenvolvido pelo grupo Farma7, com a proposta de facilitar a organização e o acompanhamento da rotina de medicamentos.

A Landing Page foi criada para apresentar o projeto, explicar seus objetivos, destacar suas funcionalidades e direcionar os visitantes ao protótipo da aplicação desenvolvido no Figma.

## Objetivo

Desenvolver uma solução tecnológica que auxilie as pessoas na organização dos medicamentos, no acompanhamento dos horários e no controle da rotina de cuidados, proporcionando mais praticidade e clareza no dia a dia.

## Estrutura da Landing Page

A página está organizada em seções para facilitar a navegação:

- **Início:** apresentação do MedRoutine e sua proposta.
- **Funcionalidades:** descrição dos principais recursos do projeto.
- **Como funciona:** explicação das etapas de utilização da solução.
- **Equipe:** apresentação dos integrantes responsáveis pelo desenvolvimento.
- **Conheça o aplicativo:** direcionamento para o protótipo no Figma.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização dos elementos da página.
- **CSS3:** estilização, identidade visual e responsividade.
- **GitHub Pages:** hospedagem e disponibilização da Landing Page na internet.
- **Visual Studio Code:** ambiente utilizado para o desenvolvimento.
